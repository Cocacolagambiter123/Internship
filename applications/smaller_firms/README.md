# Smaller-firm applications (round 2): Will McGowan

Compiled 6 October 2026. Each row has a tailored cover letter in `letters/` (Word) and `pdf/`, and all 35 are in `Will_McGowan_Cover_Letters_Smaller_Firms_2027.docx` with this tracker on the first page.

**Work rights abroad.** Work rights abroad: Ireland (Goodbody, KPMG Ireland, Virtu Dublin) needs no visa for UK citizens. Switzerland (LGT, Gunvor, Pictet), the Netherlands (Da Vinci, 3Red) and Norway or Germany (Statkraft) need a work permit for UK passport holders. If you are entitled to an Irish passport (generally true if you were born in Northern Ireland), applying for one removes that barrier across the EU.

**Back-up route.** Investment20/20 (investment2020.org.uk) runs trainee places across UK asset managers, including Edinburgh firms; register there as a back-up route into asset management.
